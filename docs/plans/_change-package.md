# 变更包模板

> **每轮开发一份**，文件名 `YYYY-MM-DD-<主题>.md`，放在 `docs/plans/`。
> 它是开发循环第 ①–④ 段的**同一份产物**：访谈决策 → 技术设计 → 追溯矩阵 → 代码 → 测试 → 验证证据。
> 用法见 [`.pi/skills/dev-loop-project/SKILL.md`](../../.pi/skills/dev-loop-project/SKILL.md)（本项目实例化）与全局技能 `dev-loop`；
> 照着填完（不留空小节），本轮就算闭合。
>
> **对外仍用本项目的分层术语**，本节给出你熟悉的对照：

| 你熟悉的说法 | 本项目里的位置 |
| --- | --- |
| PRD / 需求 | 本文件 §1 + [`../design/`](../design/README.md) 的已确认规则（`AR` `INT` `NI` 等） |
| 技术设计文档 | 本文件 §2 · [`../modules/<模块>.md`](../modules/) · [`../spec/`](../spec/) |
| 代码实现 | §4 的文件清单 + 仓库源码（模块三文件约定见 [`../design/structure.md`](../design/structure.md) §1.4） |
| 模块测试 | §5 的场景表 + 模块单测文件 + 装配层测试 |
| 验收报告 | §6 的证据行 + `make gate` / `make dev` 输出 |

> ⚠️ **只在经用户确认后才把内容升格进 [`../design/`](../design/README.md)**（`AGENTS.md` §3.1）。
> 本文件在升格前**没有**规则效力。
