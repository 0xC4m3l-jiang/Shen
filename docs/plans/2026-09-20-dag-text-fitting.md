## 1. 问题与判据

**问题（两个都属"信息看不全"）**：
1. SVG 用 `width="100%"` + `viewBox` ⇒ 链路越长整图越缩、**字号随之变小**；6 跳时已难读；
2. 每跳的值是**单行不换行**，超出固定方框就**溢出**（压到相邻跳或被视口裁掉）。

**判据**：① 字号恒定、不随链路长度变化；② 任何一跳的文字都在方框内；③ 超长内容**不丢**（悬停 + 步骤面板可看全文）。

---

## 2. 做法

| # | 决定 | 理由 |
| --- | --- | --- |
| ① | 图用**固定像素宽度**（不再 `width="100%"`），卡片容器 `overflow-x: auto` | 字号恒定；长链路用滚动看，而不是把字缩小 |
| ② | 每跳的值**按字符预算折行**（26 字符/行 × 最多 3 行），超出加省略号 | SVG 没有自动换行；折行保证在方框内 |
| ③ | 方框加 SVG `title`（悬停显示完整原文） | 折行只影响显示，信息可查 |
| ④ | 冗长失败原因（gRPC 原文）压成**短标签**（如"判定超时（DeadlineExceeded）"），完整原文放进该步的**响应**段 | 短标签保证方框内可读；原文留在步骤三段，排查不缺信息 |

## 4. 验证证据

```console
$ curl -s "http://127.0.0.1:19444/api/graphs?limit=5"   # 统计最长值
  最长值长度 = 35 （三行预算 78）

$ 失败跳（判定超时）
  方框值  : 判定超时（DeadlineExceeded）
  响应原文: 没有判定结果 ⇒ 按放行处理（原因原文：rpc error: code = DeadlineExceeded desc = context deadline exceeded）
  完整原文保留: True

$ 页面检查（重建镜像后）
  含 wrapCell / overflowX / 固定像素注释 = True；非注释 innerHTML = 0
$ make gate → 门禁通过。
```
