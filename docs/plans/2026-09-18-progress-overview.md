1. 新表覆盖 21 个有效模块的实现方式（不遗漏）。
2. 所有「方式」结论都能追到已确认规则，不写无依据的新结论。

4. `make trace` 通过（规则 ID 引用存在性 + 链接）。

**不做什么**：

- 不改任何代码 / 契约 / 模块边界。
