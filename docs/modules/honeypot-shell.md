## 1. 职责

**做什么**：

- **命令表分发**：SSH 会话里的命令 → 预设响应（假 `ls` / `cat` / `ps` / `netstat` 等）；
- **内存文件系统**：假目录树与假文件（含**会话水印凭证**，[ADR-0013](../background/decisions/0013-attribution-token.md)）；
- **文件投递**：向攻击者投递诱饵文件并记录。

**明确不做什么**：

- **不做判定** / **不做决策**（`AR-2` / `MD-12`）；
- **不执行真实命令** —— 所有响应都是预设的，**禁止**触碰宿主机；
- **不持久化状态** —— 内存文件系统按会话隔离。

## 2. 输入 / 输出契约

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 | 来自 `honeypot-protocol` 的命令 | 同上 |
| 输出 | 命令响应 + 转录事件 | `api/telemetry/v1` |
| 输出 | 会话水印（供归因） | [ADR-0013](../background/decisions/0013-attribution-token.md) |

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| 内存文件系统的数据定义 | 假文件树 |

| 禁止依赖 | 原因 |
| --- | --- |
| 宿主机文件系统 | 安全边界 —— **禁止**触碰真实文件 |
| 判定 / 决策 | `AR-2` / `MD-12` |

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `MD-15` | 资源创建与释放**必须**对称 |
| `AR-25` | 会话水印与会话 ID 绑定，三阶段一致 |
| `NI-13` | 转录保留策略 |
| `SB-6` | **禁止**主动连接目标 |
| `AR-22` | 生成内容黑名单（假文件的"泄露类"内容**必须**是假的） |

## 5. 状态与生命周期

| 状态 | 存在哪里 | 生命周期 | 多副本一致性 |
| --- | --- | --- | --- |
| 内存文件系统 | 进程内（按会话） | 会话期，结束即回收 | 各自独立 |
| 命令转录 | `store`（事件） | 按保留策略 | 强一致 |
| 会话水印 | 派生（无状态，`session` 提供） | 会话期 | 一致 |

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| 未知命令 | 返回预设的通用响应（不报"未知"） | ✅ | 保真度 |
| 会话结束 | 内存文件系统回收 | ✅ | `MD-15` |
| 生成内容命中黑名单 | 丢弃并回退预设 | ✅ | `AR-22` |
