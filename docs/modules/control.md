## 1. 职责

### 做什么

- gRPC 服务面：接收适配器的判定请求与遥测上报，回传结果。
- **禁止回显的强制点** —— 返回体不得含风险分值、规则名、决策枚举。
- 入参映射：proto → 内部类型；并在此提取会话身份。

### 明确不做什么

- **不做判定** —— 判定在 `judge`，决策在 `director`，本模块只做映射与转发。
- **不做重试与补偿** —— 可靠重放由核心侧的接收缓冲负责。
- **不实现业务规则** —— 非法值回落等由内部类型层处理。

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `ST-7` | 禁止在对外响应中回显分值 / 规则名 / 决策枚举 —— 本模块是强制点 |
| `NI-5` / `V-4` | 非法决策值一律回落为放行 |
| `AR-11` | 遥测面必须幂等 |
| `MD-4` | 依赖方向单向 |

## 5. 状态与生命周期

| 状态 | 存在哪里 | 生命周期 | 多副本一致性 |
| --- | --- | --- | --- |
| 无 | —— | 每个请求独立处理 | 天然一致 |

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| 决策层返回错误 | 返回 gRPC 错误，由**适配器侧 fail-open** 放行 | ✅ | `NI-4` / `NI-5` |
| 会话提取失败 | 返回 gRPC 错误（同上） | ✅ | `NI-5` |
| 决策值非法 | 映射为放行，不报错 | ✅ | `V-4` |
| 遥测写入失败 | 返回错误，不影响判定面 | ✅ | 遥测不阻断请求 |
