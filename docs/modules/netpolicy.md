| 负责人 | — |

| 最后更新 | 2026-09-18 |

---

## 1. 职责

**做什么**：

- **微隔离**：按策略限制蜜网内的东西向流量；
- **假拓扑**：构造看起来真实的内网结构（假主机 / 假服务）；
- **运行时检测与阻断**：基于 eBPF 的运行时行为检测。

**明确不做什么**：

- **不做判定**（`AR-2`）/ **不做决策**（`MD-12`）—— 它执行的是 `policy` 下发的声明式规则；
- **不向被接入业务之外的主机投递载荷或发起连接**（`SB-5`）；
- **不自研 eBPF 底座** —— 复用 Cilium / Tetragon（复用三原则①）。

## 2. 输入 / 输出契约

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 | 声明式网络策略（来自 `policy`） | [`../spec/config.md`](../spec/config.md) |
| 输出 | 隔离 / 阻断动作 + 运行时事件 | `api/telemetry/v1` |

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| Cilium / Tetragon（复用开源） | 复用三原则①：隔离层复用开源 |
| 内核 eBPF 能力 | 数据面 |

| 禁止依赖 | 原因 |
| --- | --- |
| 判定 / 决策逻辑 | `AR-2` / `MD-12` |
| 自研 eBPF 底座 | 浪费（复用三原则①） |

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `SB-5` | **禁止**向被接入业务之外的主机投递载荷或发起连接 |
| `SB-6` | 引擎是被动组件 |
| `SB-8` | 抓取 / 克隆类能力**必须**配置目标白名单；私网与云元数据默认阻断 |
| `AR-4` | 每层只选一个组件，**禁止**多层代理叠加 |
| `NI-7` | 受 cgroup / 资源上限约束 |
| `TB-23` | Rust 组件须 `#![forbid(unsafe_code)]`，eBPF 数据面例外须有安全注释 |

## 5. 状态与生命周期

| 状态 | 存在哪里 | 生命周期 | 多副本一致性 |
| --- | --- | --- | --- |
| 网络策略 | 声明式配置（`policy` 下发） | 版本化 | 强一致 |
| 运行时事件 | `store`（事件） | 按保留策略 | 强一致 |

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| 策略下发失败 | 沿用当前策略 | ✅ | `ST-8` |
| eBPF 程序加载失败 | 降级为无隔离（不阻断业务） | ✅ | `NI-1` |
