## 1. 职责

### 做什么

- 核心**唯一**的 I/O 出口：所有对 Redis / ClickHouse / PostgreSQL 的访问都经本包。
- 按实体拆成小接口，让每个核心模块只依赖它用得着的那一个。
  （`ContentStore` 是其中**唯一有明确生命周期约定**的一个：键 = 一致性键，内容由离线生成、热路径只读；
  自 2026-09-20 起有真实消费方 —— `policy` 装载期 `Put` / 投影期 `Get`，见 [ADR-0023](../background/decisions/0023-deception-content-injection.md)）

### 明确不做什么

- **不反向依赖任何业务模块** —— 本包在最底层，只能被上层调用。
- **不做判定** —— 只存与取。

## 2. 输入 / 输出契约

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 / 输出 | `SessionStore` / `IsolationStore` / `DecisionStore` / `EventStore` / `PolicyStore` / `DecoyStore` / `ContentStore` | `core/internal/store/iface.go` |
| 阶段 1 实现 | `Memory` 系列（每个实体一个类型） | `core/internal/store/memory.go` |

> 为什么按实体拆：Go 不支持方法重载，一个结构体无法同时实现两个都有 `Get`/`Put` 的接口。
> 拆开还让单测替身只需实现它用到的那一两个方法。

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| `contract` | 共享类型 |

| 禁止依赖 | 原因 |
| --- | --- |
| 任何业务模块（`judge` / `director` / …） | 反向依赖会让存储层知道业务，耦合失控 |

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `MD-20` | 核心模块访问存储必须经本包；本包禁止反向依赖 |
| `MD-22` | 内存实现让单测不依赖真实数据库 |
| `ST-8` | 策略版本只增，回滚即发布新版本 |
| `ST-15` | Redis 不可用时的降级行为必须测试 |

## 5. 状态与生命周期

| 状态 | 存在哪里 | 生命周期 | 多副本一致性 |
| --- | --- | --- | --- |
| 会话 | Redis（阶段 2）/ 内存（阶段 1） | TTL 过期自动回收 | 由存储层保证 |
| 隔离名单 | Redis 生效 + PostgreSQL 审计 | TTL 到期自动解除 | 跨适配器靠缓存刷新（≤ 1s） |
| 判定结果 | Redis 缓存 + ClickHouse 归档 | 缓存 TTL；归档只增 | 最终一致 |
| 事件 | ClickHouse（阶段 2） | 只增不改，按天分区 | 幂等键去重 |
| 策略 | PostgreSQL（阶段 2） | 版本只增 | 单写入方 |

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| Redis 不可用 | 隔离名单读不到 → 上层回退到调核心判定（放行） | ✅ | `NI-10` / `ST-15` |
| 同 `EventID` 重复写 | 返回"未写入"，不报错 | ✅ | `AR-11` |
| 事件缺 `EventID` | 报 `ErrEmptyEventID` | ✅ | 拒绝脏数据 |
| 未发布过策略 | 返回 `ErrNoPolicy`（不返回零值） | ✅ | 显式失败优于静默零值 |
| 策略版本不递增 | 拒绝发布 | ✅ | `ST-8` |
