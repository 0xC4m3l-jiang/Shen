## 1. 职责

**做什么**：

- **协议仿真**：SSH / MySQL / Redis / FTP / ElasticSearch / nginx-admin 等真实协议栈的假服务；
- **交互捕获**：逐命令 / 逐查询转录，凭证捕获，文件投递记录。

**明确不做什么**：

- **不做判定**（`AR-2`）· **不做决策**（`MD-12`）；
- **不主动连接任何目标** —— 它只承接 `honeypot` 路由来的流量（`SB-6`）；
- **不与判别同进程** —— 独立进程 / 容器（`MD-4` 依赖方向）。
- ⚠️ **本模块是可选自研**：默认由 `honeypot` 接第三方蜜罐（[ADR-0011](../background/decisions/0011-honeypot-entry-external-backends.md)）。

## 2. 输入 / 输出契约

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 | 承接 `honeypot` 路由来的流量（协议端口） | [`../modules/honeypot.md`](honeypot.md) |
| 输出 | 事件（会话转录 / 凭证捕获 / 文件投递） | `api/telemetry/v1` |

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| 协议库（paramiko 类等价物） | 真协议栈 |

| 禁止依赖 | 原因 |
| --- | --- |
| 判定 / 决策 | `AR-2` / `MD-12` |
| 核心内部包 | 依赖方向单向（`MD-4`） |

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `MD-14` | 子进程**必须**按进程组回收 + 双层超时 |
| `MD-15` | 资源创建与释放**必须**对称 |
| `MD-16` | 并发连接数 / 线程数**必须**设上限 |
| `NI-7` | **必须**受 cgroup 上限约束 |
| `NI-13` | 会话转录按类别配置保留天数 |
| `AR-25` | 会话 ID 作为一等字段，建立 / 心跳 / 收尾一致 |
| `SB-6` | **禁止**主动连接目标 |

## 5. 状态与生命周期

| 状态 | 存在哪里 | 生命周期 | 多副本一致性 |
| --- | --- | --- | --- |
| 会话转录 | `store`（事件） | 按保留策略 | 强一致 |
| 凭证捕获 | `store`（凭证观察库） | 按保留策略 | 强一致 |
| 运行态 | 进程内（连接 / 子进程） | 会话期 | 各自独立 |

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| 子进程超时 | 按进程组 `SIGTERM` → 宽限 → `SIGKILL` | ✅ | `MD-14` |
| 连接数超限 | 拒绝并记录 | ✅ | `MD-16` |
| 蜜罐不可达 | `route_mirage` 回落业务（`honeypot` 侧） | ✅ | `NI-5` |
