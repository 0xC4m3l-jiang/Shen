## 1. 职责

### 做什么

- 事件归一化与**幂等**批量上报：同一个 `event_id` 重复上报不产生重复记录。
- 给出上报回执（写入几条、重复几条），供适配器对账。

### 明确不做什么

- **不做持久缓冲** —— 适配器侧不承担持久缓冲，可靠重放由核心侧的接收缓冲与落库补偿负责。
- **不依赖系统时钟** —— 事件时间由调用方注入。
- **不自己实现去重存储** —— 去重能力由 `store.EventStore` 提供。

## 2. 输入 / 输出契约

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 | `contract.Event`（含幂等键 `EventID`） | `core/internal/contract/` |
| 输入 | `Sink.Write`（由 `store` 实现的幂等写入） | `core/internal/telemetry/iface.go` |
| 输出 | `telemetry.Result`（`Accepted` / `Duplicated`） | 同上 |

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| `contract` | 共享类型 |

| 禁止依赖 | 原因 |
| --- | --- |
| `store` 具体实现 | 接口由消费方定义，便于单测替身 |

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `AR-11` | 遥测上报必须幂等 —— 本模块的核心约束 |
| `MD-6` | 不依赖系统时钟 |
| `MD-22` | 单测必须能独立运行（用 `Sink` 替身） |

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| `Sink` 返回错误 | 向调用方返回错误，已写入的计数照常返回 | ✅ | 调用方（适配器）决定是否重试 |
| 事件缺少 `EventID` | **丢弃该事件**，不写入 | ✅ | 没有幂等键就无法保证去重，宁可丢也不写脏数据 |
| 存储不可用 | 同上，错误上抛 | ✅ | 遥测不阻断请求路径 |
