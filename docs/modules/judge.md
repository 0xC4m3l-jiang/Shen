## 1. 职责

### 做什么

- 把一次观测变成一个判定结果：风险分、命中的信号、可回放的证据链。
- 按**数据形态**的规则求值（规则不是 Go 分支，而是可下发的配置）。
- **Agent 指纹识别**：对 UA / 请求头做多信号签名匹配，产出产品标识 + **置信度** + 证据链
  （依据 [ADR-0010](../background/decisions/0010-functional-camouflage.md) 与参考实现逆向 §3.1.2）。
- **消费会话特征**：速度、挑战逃逸等会话级特征**随输入进来**（本模块不持有状态，见 [ADR-0012](../background/decisions/0012-session-level-judgement.md)）。

### 明确不做什么

- **不决定去哪儿** —— 那是 `director` 的职责。本模块只回答「风险多大」，不回答「送去哪里」。
- **不做任何 I/O** —— 不发起外呼、不写存储、不读文件。
- **不依赖系统时钟** —— 需要时间时必须由调用方注入，否则判定不可回放。
- **不持有会话状态** —— 会话级特征由 `session` 计算后注入（[ADR-0012](../background/decisions/0012-session-level-judgement.md)）；本模块保持**纯函数**。
- **不做 LLM 推理** —— 指纹是签名匹配，不是模型推断（`TB-22`）。

## 2. 输入 / 输出契约

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 | `RuleSource.Rules` 提供的规则集（数据） | `core/internal/judge/iface.go` |
| 输入 | `contract.JudgeRequest`（观测 + 会话 + **会话特征** + 幂等键） | `core/internal/contract/` |
| 输入 | `contract.SessionFeatures`（速度 / 挑战逃逸 / 首末次时间） | 同上（[ADR-0012](../background/decisions/0012-session-level-judgement.md)） |
| 输入 | 指纹签名库（数据） | [`../spec/config.md`](../spec/config.md) 的 `fingerprints` 段（待建） |
| 输出 | `contract.Verdict`（分数 + 信号 + 证据 + **指纹**） | `core/internal/contract/` |

对外（跨进程）契约不在这里 —— 那是 `api/judge/v1` 的 proto。

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| `contract` | 共享类型 |
| `RuleSource`（接口，由 `policy` 实现） | 规则由策略层下发 |

| 禁止依赖 | 原因 |
| --- | --- |
| `store` / Redis / ClickHouse / PostgreSQL | 核心唯一的 I/O 出口是 `store`，判定本身不该碰存储 |
| 任何网络库 | 判定必须在纯内存里完成 |

> 接口由**消费方**定义，所以本模块不 import `policy` —— 依赖方向单向。

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `AR-2` / `AR-5` | 本模块是判定逻辑的**唯一**实现处；边缘层与适配器都禁止实现判定 |
| `MD-6` | 禁止外呼、禁止写业务存储、禁止依赖系统时钟 |
| `MD-7` | 每条判定规则**必须**有正样本与负样本用例（指纹签名同理） |
| `MD-8` | 判定分支**必须**有穷尽性测试 |
| `ST-24` | 规则与指纹签名都是**数据**，不是编译进代码的分支 |
| `NI-5` | 未识别 / 未匹配一律回落零分（放行） |

### 4.1 指纹的置信度阶梯（设计，依据参考实现）

| 命中情况 | 置信度 |
| --- | --- |
| 强 UA 标记 | 0.9 |
| UA 前缀匹配 | 0.75 |
| 弱 UA 标记 | 0.6 |
| 每命中一个特征头 | +0.03（下限 0.65） |
| 头对（`header_pairs`）命中 | +0.05（下限 0.75） |
| 封顶 | 0.98 |

> 指纹**必须**产出 `evidence: []string`（「为什么认为是它」），供审计与回放。
> **本模块的指纹库自行整理，不照搬参考实现的签名表** —— 后者为 AGPL-3.0，照搬有许可风险
> （见 [`../background/research/agentcapture-deception-report.md`](../background/research/agentcapture-deception-report.md) §8.3）。

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| 规则源返回错误 | 向调用方返回错误 | ✅ | 由 `director` 层回落放行 |
| 未命中任何规则 | 返回零分判定 | ✅ | `NI-5`（未识别即回落放行） |
| 规则集为空 | 同上，全零分 | ✅ | 同上 |
