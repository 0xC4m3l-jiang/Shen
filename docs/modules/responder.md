## 1. 职责

**做什么**：

- 生成**欺骗式响应**：组装「看起来像真实业务」的状态码 / 响应头 / 响应体；
- **快路径**：模板 + **确定性伪随机**（种子 = `hash(会话键, 资源键)`），毫秒级、进程内；
- **慢路径**：读 `store` 中由 `llm-components` 预生成的高保真内容；
- 兑现一致性不变量：**同一 `(会话, 资源)` 永远返回同一答案**（`AR-30`）。

**明确不做什么**：

- **不调 LLM** —— 本模块是核心模块，**禁止**外呼（`MD-6`）；LLM 内容由 L4 **离线/近线**预生成后落库；
- **不改写业务侧响应** —— 改写**只能**作用于蜜罐侧（`INT-8`）；
- **不做判定**（`AR-2`）与**不做决策**（`MD-12`）；
- **不在响应里回显判定信息**（`OH-5` / `ST-7`）。

## 2. 输入 / 输出契约

跨模块与对外的契约不在这里（`MD-3`），只引用：

| 方向 | 契约 | 定义位置 |
| --- | --- | --- |
| 输入 | 诱饵内容定义 | [`../modules/decoy.md`](decoy.md) |
| 输入 | 预生成内容（按 `(会话, 资源)` 键） | `store` 的内容缓存实体 |
| 输入 | 请求（方法 / 路径 / query）+ 会话键 | `contract` |
| 输出 | 伪造响应（状态码 / 头 / 体） | `contract.ResponderOutput`（待定） |

本模块内部数据结构：`Template`（模板）、`Seed`（一致性种子）、`Response`（组装结果）。

## 3. 依赖

| 允许依赖 | 原因 |
| --- | --- |
| `contract` | 进程内共享类型 |
| `store` | 读预生成内容（唯一 I/O 出口，`MD-20`） |

| 禁止依赖 | 原因 |
| --- | --- |
| **任何 LLM 运行时 / 外呼** | `MD-6`：核心禁止外呼；热路径不放 LLM（[ADR-0014](../background/decisions/0014-generative-deceptive-response.md)） |
| `judge` / `director` | 依赖方向单向（`MD-4`） |

## 4. 关键规则

| 规则 | 与本模块的关系 |
| --- | --- |
| `AR-30` | **一致性不变量**：同 `(会话, 资源)` 必得同一响应；**禁止**非确定性（随机数 / 当前时间 / LLM 采样） |
| `INT-8` | 响应改写**只能**作用于蜜罐侧；**禁止**改写业务侧响应 |
| `AR-22` | 生成内容**必须**过黑名单（泄露类 / 自曝类 / 超长类） |
| `ST-22` | 话术与模板**必须**随代码分发，**禁止**运行期可变存储 |
| `MD-23` | 不得产生可归因于防御行为的信号（不加响应头 / 不改状态码语义 / 不引入新 cookie） |
| `NI-9` | **禁止**新增客户端可见的 Cookie 或响应头 |
| `OH-1` / `OH-5` | 内容**禁止**含禁用串；**禁止**回显分值 / 规则名 / 决策枚举 |
| `NI-5` | 内容缺失时回落真实业务，**禁止**用半成品顶替 |

## 5. 状态与生命周期

| 状态 | 存在哪里 | 生命周期 | 多副本一致性 |
| --- | --- | --- | --- |
| 预生成内容 | `store` 的内容缓存实体 | 按保留策略 | 强一致（经 `store`） |
| 模板 | 代码仓库内资源（`ST-22`） | 随版本 | 各副本一致 |
| 种子 | 无（由 `(会话, 资源)` 现算） | —— | 天然一致 |

> 规则 `AR-9`：核心无状态多副本；本模块不持有跨请求状态。

## 6. 失败模式与降级

| 失败情形 | 行为 | 是否满足 `NI-1` | 依据 |
| --- | --- | --- | --- |
| 预生成内容未命中 | 回落确定性模板（快路径） | ✅ | `AR-30`（一致性优先于保真） |
| 模板缺失 | 回落真实业务（不伪造） | ✅ | `NI-5` |
| 内容黑名单命中 | 丢弃该内容，走模板 | ✅ | `AR-22` |
| 存储不可用 | 只走模板，业务不受影响 | ✅ | `NI-3` |
