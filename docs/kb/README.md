## 怎么写一条（新人补充请照此）

**已知问题**必须写清三样，缺一样就没用：

1. **症状** —— 你看到什么（报错原文 / 现象描述）
2. **原因** —— 为什么会这样
3. **结论** —— 现在怎么做

**不写**「以后可能需要注意」这类没有动作的话。写完在 [`known-issues.md`](known-issues.md) 开头分类表里补一行（现行 / 历史）。
