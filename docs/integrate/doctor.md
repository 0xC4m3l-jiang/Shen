# 接入自检（`shen doctor` · `INT-17` 五项）

> **什么时候用**：把站点接进来的**当天**、以及每次改接入物料之后。它回答一句话：**这台部署到底有没有真的在链路上工作**。
> 命令：`scripts/shen.sh doctor`（= `make doctor`）· 也可 `python3 scripts/doctor/doctor.py --entry … --console … --origin … --json`

## 五项与判据

| # | 检查项 | 怎么验（工具实际做的） | 结论含义 |
| --- | --- | --- | --- |
| ① | **body 是否可读** | 发一个带唯一标记的 POST，再去观测面找这个标记 | 有标记 ⇒ 可判 body；**没有** ⇒ 按 `INT-22`：**只能观察，禁止启用误导处置**（约束，不是失败） |
| ② | **TLS 是终结还是透传** | 分别向入口发明文与 TLS，看谁应答、证书是谁 | 明文应答 ⇒ 由前置 L0 终结（`ADR-0019` 的默认形态）；引擎自终结会打印证书 subject/issuer |
| ③ | **会话粘性** | 同会话 cookie 打两次同路径，比对 `decision_id` | 相同 ⇒ `ST-10` 判定缓存按会话黏住；不同 ⇒ 会话没粘住 |
| ④ | **实境与幻境可区分** | 观测里找 `route_mirage` 判定 | 有 ⇒ 打印一次改道的响应形状；**没有** ⇒ 如实说"无法判定"（影子模式 / 未登记可用幻境后端） |
| ⑤ | **引擎是否真的在请求路径上** | 带唯一标记的请求应出现在观测面；可选 `--origin` 直连对照 | 观测面有这条判定 ⇒ 在路径上；直连业务不应新增判定 |

## 怎么读结果（四种状态）

| 状态 | 含义 | 你该做什么 |
| --- | --- | --- |
| ✅ 通过 | 验到了，且符合设计 | 无 |
| ❌ 失败 | 验到了，**不符合**设计 | 按输出里的「怎么办」处理；两处常见：不在路径上（上游指向不对）· 会话没粘住（看适配器日志的 `decision_id`） |
| ⚠️ 约束 | 验到了，但结论**限制你能做什么**（如 body 不可读 ⇒ 不得启用误导处置） | 记进接入方案；不要绕过 `INT-22` |
| ➖ 无法判定 | 这次**验不了**，输出会写清原因与关法 | 按原因补齐前置（例如登记幻境后端），再重跑 |

## 退出码

`0` = 五项都有结论且无失败 · `1` = 有失败项 · `2` = 入口或控制台不可达（先 `scripts/shen.sh status`）。

## 一个实测例子（本机 Docker 栈）

```console
$ scripts/shen.sh doctor
➖ ① body 可读        无法判定：该 POST 拿到上游响应（HTTP 501）但无判定记录 ⇒ 在路径上、这次没判
✅ ② TLS 终结方式      通过：入口是明文 HTTP ⇒ 由前置 L0 终结（ADR-0019 默认）
✅ ③ 会话粘性         通过：同会话两次复用同一 decision_id（ST-10 生效）
➖ ④ 实境/幻境可区分   无法判定：观测里没有 route_mirage（影子模式 / 未登记后端）
✅ ⑤ 引擎在请求路径上   通过：经引擎请求 200 且观测面有判定
结论：通过 3 · 失败 0 · 约束 0 · 无法判定 2
```

> ①「这次没判」的典型原因是**判定超时后放行**：重启后第一条请求的 gRPC 建连超出判定预算（3ms），
> 引擎按 `NI-3` 放行到真实业务（**业务不受影响**），但这条没有判定记录。重跑本项即可。
> 详见 [`../kb/known-issues.md`](../kb/known-issues.md) `K-24`。

## 与其它工具的分工

| 工具 | 干什么 | 不干什么 |
| --- | --- | --- |
| `scripts/shen.sh doctor`（本页） | **接入自检**：这台部署在链路上到底工作不工作 | 不验证判定准不准（那是 `traffic`）· 不做逐字段 diff（那是哨兵） |
| `scripts/shen.sh traffic` | **判定验证**：33 个场景核对分数/信号（[`../ops/functional-verification.md`](../ops/functional-verification.md)） | 不检查接入形态是否装对 |
| `scripts/sentinel` | **差异哨兵**（⏳ **待实现**）：同一组 URL 在真实业务与幻境各打一次，逐字段 diff（12 项） | — |
