# 接入与使用（`integrate/`）

> **受众**：要**把业务接进来**的人（接入方）· 要**日常使用/观察**的人（运维与运营）· 要**做人工测试**的人（研发）。
> **规则源头**在 [`../design/`](../design/README.md)（`INT-1`…`INT-25` · `NI-*` · `OH-*`）；本目录只讲**怎么做**。

| 我想… | 看哪份 |

| 5 分钟把环境跑起来、并看到数据 | [`quickstart.md`](quickstart.md) |

## 三条必须先知道的

1. **首次上线必须影子模式**（`INT-11`）：照算判定、照上报，但**永不改道、永不拦截**。默认就是它。
2. **判定分数与命中信号不在响应里**（`ST-7` 禁止回显）—— 只能在**观测台**看。这是本项目最反直觉的一点。
3. **引擎完全故障时业务 100% 正常**（`NI-1`）：这不是承诺，是 `V-1…V-4` 自动化测试在守的底线（见 [`../modules/adapter-proxy.md`](../modules/adapter-proxy.md) §7）。
