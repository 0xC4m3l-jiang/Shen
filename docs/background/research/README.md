## 2. 调研是怎么做的（方法记录）

| 阶段 | 做法 | 产出 |
| --- | --- | --- |
| ① 领域建图 | 按四个轴拆解：欺骗防御 / 流量代理 / WAF / 负载均衡 | 综述的轴一～轴四 |
| ② 全量检索 | arXiv API（`export.arxiv.org/api/query`，按 relevance + submittedDate）为主，联网学术检索为辅；重点 2024–2026，经典工作回溯至 2015 | 59 篇文献 |
| ③ 筛选 | 优先系统 / 机制类 > 评测基准 > 综述；剔除纯红队工具介绍 | 分层清单 |
| ④ 交叉空白分析 | 把领域拆成交叉组合，标注「已有工作 / 缺口 / 评级 / 依据」 | 空白区 A–F |
| ⑤ 一手逆向 | 逐文件精读参考实现源码（24.7k 行 Python，重点 10 个模块） | `agentcapture-deception-report.md` |
| ⑥ **证据分级** | 甲（原文核验）/ 乙（通行本多源一致）/ 丙（未核验，不引用） | 命名设计、逆向报告 |
| ⑦ **引用核验** | 59 个 arXiv ID 逐条通过 arXiv API 核验 | **59/59 全部存在** |
| ⑧ 反证与审计 | 对自身材料做覆盖度审计，专找缺口与偏差 | `knowledge-base-audit.md` |

**可复用的流程**见技能 [`.pi/skills/evidence-and-decisions/SKILL.md`](../../.pi/skills/evidence-and-decisions/SKILL.md) 的 §1（调研）。

### 两条方法纪律

| # | 纪律 |
| --- | --- |
| 1 | **ID 存在 ≠ 内容被读过。** 引用核验只证明来源真实；「逐篇深读」是另一件事，本项目尚未做（缺口 G11）。当前对文献的理解深度是**摘要级 + 二手转述**，不是方法级。 |
| 2 | **宣传口径不得作为基线。** 无原始实验数据的自述一律标为 C 级，不得用于对比。 |

## 3. 关键结论汇总

| # | 结论 | 来源 |
| --- | --- | --- |
| 1 | **59 个 arXiv ID 全部真实存在**（59/59，经 arXiv API 核验） | 本轮核验 |
| 2 | 参考实现**没有调度层** —— 处置是内联响应，不是路由 | 逆向报告 |
| 3 | **显式提示注入对已对齐模型无效**（其自测 0/8 服从）；有效的是**功能性伪装** | 逆向报告 |
| 4 | **判别必须会话级有状态** —— 但仅用于「加重处置」；**路由**必须首跳定终局 | 逆向报告 + 本项目推导 |
| 5 | 空白区 A/B/C 在论文层成立；**B（LB 作诱饵调度器）最干净** | 综述 + 审计 |
| 6 | 规则型 WAF 对新变体检测率 **< 12%** → 量化了「不靠拦截靠欺骗」的动机 | 综述 |
| 7 | 静态诱饵会被**渐进识破** → 诱饵需多态 + 调度需学习 | 综述（AgentSnare 等） |
| 8 | ~~命名与术语体系已定稿~~ **已废弃**：命名体系整体推翻，技术术语改用行业术语（[ADR-0004](../decisions/0004-terminology.md)）；语源考据仅存历史价值 | 命名设计 |

> ⚠️ **第 4 条曾被误读为矛盾**：原稿把「判别必须会话级有状态」与「路由必须首跳定终局」并列陈述。
> 正确的表述是：**判别可累积用于「加重处置」；「路由」必须会话粘性且首跳确定。** 详见
> [`../notes/implementation-discussion.md`](../notes/implementation-discussion.md) §1。

## 5. 如何登记新材料

1. 用技能 `evidence-and-decisions` §1（检索 → 结构化提取 → 空白矩阵 → 证据分级）；
2. 新找到的材料**放本目录**，命名 `<主题>.md`，并在 §1 表格登记一行（含**行数、性质、证据级、讲了什么**）；
3. 任何新增引用**必须**先核验 ID / venue，核不到标「待核」且**不得**写入结论；
4. **若有内容与 `design/` 基线冲突**：按 `AGENTS.md` **P-3** 停下并报告，
   在文件头加横幅说明冲突点与裁定结果，**不得**由 Agent 自行合并；
5. 结论中若有用户确认的部分，按 `AGENTS.md` §3 升格到 `../../design/`，并在本目录原处标注；
   选型类结论走 [`../decisions/`](../decisions/README.md)。
