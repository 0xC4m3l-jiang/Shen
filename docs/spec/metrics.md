# 规格：指标（`metrics.md`）

> **状态**：🟡 **部分采集**（2026-09-19）。
> `AR-28` 要求「§6 的指标项**必须**全部有采集点与告警阈值；**禁止**只定义不采集」——
> 本文按现状如实登记：**已采集**的给出采集点与阈值；**未采集**的列出缺口与关法（不假装有）。
> 权威数值区间见 [`../design/architecture.md`](../design/architecture.md) §6。

## 1. 已采集（今天就能拿到）

| 指标 | 口径 | 采集点 | 阈值 / 判据 |
| --- | --- | --- | --- |
| **判定数 · 按决策分布** | 时间窗内 `action` 三值计数 | 核心观测记录器 → 事件 → 控制台 `GET /api/summary`（`by_action`） | 影子模式下 `route_mirage`/`block` **必须为 0**（`INT-11`）；非 0 即接入配错 |
| **风险分分布** | 每条判定的 `score`（命中权重和，1.0 截断） | 逐判定日志（[`logs.md`](logs.md) §3）· 控制台 `GET /api/flow` | 引流阈值 `thresholds.route_mirage`（默认 0.70）· 拦截阈值 `thresholds.block`（默认 0.95），见 [`config.md`](config.md) |
| **命中信号明细** | 每条判定命中的规则 `id` 列表 | 同上（`signals` 字段） | 无阈值；用于解释"为什么这个分" |
| **告警条数** | `action=block` **或** `severity≠none` 的条数 | 控制台 `GET /api/summary`（`alerts`） | 当前**恒为 0**：`severity` 档位未定（见 §2） |
| **误调度预算** | 误改道比例上限 | 配置 `guard.false_route_budget`（默认 0.001 = 0.1%） | 超限即回退放量（`INT-12` 的阶梯） |
| **事件幂等 / 重复上报** | `ReportAck.accepted` 与 `duplicated` | 遥测面响应 · 适配器日志「遥测上报失败」 | 重复不得产生重复记录（`AR-11`）；`duplicated>0` 属正常 |
| **L4 态势去重率** | 每轮 `取事件 N · 去重后 M · 结论 K` | L4 worker 日志（每轮一行） | `AR-14`：结论数**不得**随事件量线性增长 |
| **L4 证据引用完整性** | 结论引用的 `evidence_ids` 是否都真实存在 | `scripts/traffic/send.py --check-l4`（读控制台 `/api/analysis` 与 `/api/flow`） | 出现悬空引用即失败（`AR-12`） |
| **业务路径额外延迟下界** | 直连 vs 经引擎的 P99 差 | `make bench`（本地基准，非运行时采集） | `AR-29`：≤ 5 ms；实测空载 **+≈48 µs** |
| **引擎可用性对业务的影响** | 引擎故障时业务成功率 | `scripts/shen.sh traffic`（每场景断言状态码）· `V-1…V-4` 故障注入（`make gate` 内） | `NI-1`：**必须** 100% 正常；任何 5xx 都是失败 |

## 2. 未采集（`AR-28` 的缺口，别当已实现）

| 指标（设计 §6 定义） | 为什么还没有 | 怎么关 |
| --- | --- | --- |
| **真实延迟分布（P50/P99 运行时）** | 已有**逐请求**耗时（`request_judged.duration_ms`，见 `/api/trace`），但没有分位统计 | 在拓扑/指标接口上加分位聚合（或接 Prometheus 导出） |
| **误调度率的线上观测值** | 只有预算配置，没有实测采集（需要与业务日志/直连对照） | 哨兵 + 线上抽样对照 |

## 3. 规矩

1. **新增指标**：先在本文件登记（口径**含分母** · 单位 · 采集点 · 正常范围 · 越界动作），再写代码 —— `AR-28` 禁止"只定义不采集"，同样禁止"只采集不登记"；
2. **不要用日志当指标**：日志可丢、不可聚合（[`logs.md`](logs.md) §6）；要长期观测的必须落到事件或专门的导出面；
3. **阈值的权威在配置**：本文件只写"去哪看阈值"，数值以 [`config.md`](config.md) 与 [`../design/architecture.md`](../design/architecture.md) §6 为准（避免三处维护）。
