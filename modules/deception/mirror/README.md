# 适配器 · ① 旁路镜像

| 项 | 值 |
| --- | --- |
| 所属层 | L1 |
| 语言 | 配置 + Go |
| 阶段 | **1（MVP，最先做）** |
| 模块文档 | [`../../docs/modules/adapter-mirror.md`](../../../docs/modules/adapter-mirror.md) |

## 它是什么

把流量**复制一份**给引擎，引擎**只观察、不处置、不回写**。

- 引擎**不在请求路径上** → `NI-3`（失败放行）/ `NI-4`（硬超时）/ `NI-10`（熔断）/ `AR-6`（拦截）/ `AR-7`（处置）**均不适用**（`INT-6`）
- 它天然满足 `NI-11`（首次上线必须是影子模式）—— 这正是把它排在第一位的原因

## 部署前提

| # | 前提 | 依据 |
| --- | --- | --- |
| 1 | 镜像方式二选一：LB 请求镜像 / `iptables TEE` / eBPF | `INT-1` |
| 2 | 引擎只**接收**副本，不产生任何出站连接 | `SB-5` / `SB-6` |
| 3 | 副本里的会话身份仍按 `INT-19` 三级优先级提取 | `INT-19` |

## 目录内容

| 路径 | 内容 |
| --- | --- |
| `config/` | 镜像规则模板：`iptables-tee.example.sh` · `nginx-mirror.example.conf` · `envoy-mirror.example.yaml` |
| `receiver.go` | ✅ 接收端：把镜像请求转成判定请求并调核心（含单测 3 例） |
| `cmd/mirror/` | ✅ 进程入口 |

## 配置

| 环境变量 | 默认 | 含义 |
| --- | --- | --- |
| `SHEN_MIRROR_LISTEN` | `127.0.0.1:8082` | 接收端监听地址：镜像流量的出口 |
| `SHEN_CORE_ADDR` | `127.0.0.1:9443` | 核心判定/遥测面的 gRPC 地址 |

> 接收端**恒回 202**：它在请求路径之外，不对客户端表达任何意见（`INT-6` / `AR-7`）。
> 它的 HTTP 形态适用于 **LB 请求镜像**；若改用 `iptables TEE` / eBPF，副本是原始 TCP 流，
> 需要先重组才能到本接收端 —— 那属于 L0 物料的一部分（见 `docs/design/architecture.md` §10.2）。
