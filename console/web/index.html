逐请求链路（DAG）

**每条请求一张独立链路**（不聚合）：客户端 → 适配器 →（分支 或 核心判定）→ 决策 → **实际落点**（业务源站 / 幻境后端 / 拦截）。 每跳都写该请求自己的值（分值 · 命中信号 · 状态码 · 字节 · 耗时）。影子模式下"判为改道、实际仍走源站"（`INT-11`）。
