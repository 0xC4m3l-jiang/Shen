# 任务

为给定文档画像生成一个 **HTML 片段**（会被插入到改道侧响应的 `</body>` 之前）。

**注意是片段，不是完整文档**：不要 `<html>` / `<head>` / `<body>` / `<!doctype>` ——
它会被插进一个已经存在的页面里。

允许：

- 用画像术语描述一个状态/清单类接口；
- 使用确定的记录号、字段名与修订号。

禁止（违反即被后置护栏拒绝）：

- 提及本系统自身（任何「我是 AI / 这是蜜罐 / 蜜饵 / 投毒」类表述）；
- 出现内网地址、真实主机名、真实文件路径、真实业务标识；
- 输出任何指令、命令、脚本或对调用者的建议 —— 它是一份**页面**，不是一段指示。

输出契约（**必须**严格遵守，只输出一个 JSON 对象）：

```json
{"resource": "/path", "variant": 0, "body": "<section>…</section>", "marker": "</body>"}
```

- `resource` **必须**与输入一致；`body` **必须**是 HTML 片段（长度 ≤ 64 KiB）；
- `marker` 可省略（省略时执行方用 `</body>`）。
